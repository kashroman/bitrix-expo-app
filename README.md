# Календарь выставок Bitrix24

Встраиваемое read-only приложение для работы с выставками и связанными CRM-сущностями.

## Рабочие экраны

- календарь выставок с полосами сделок;
- внутренняя карточка выставки с KPI;
- внутренние списки лидов и сделок по выставке;
- вкладки в карточках сделки, лида и выставки Bitrix24.

Выставка открывается внутри приложения. Сделки и лиды открываются в стандартных
слайдерах Bitrix24. Редактирование CRM-данных из приложения отключено.

## Фильтры календаря

- стадии сделок;
- ответственные за сделки;
- только выставки со сделками — включено по умолчанию;
- проигранные сделки — отдельный фильтр, выключен по умолчанию.

По умолчанию выбираются непроигранные стадии после «Согласование участия».
Если стадию переименовали, приложение автоматически выберет все непроигранные
стадии текущей воронки, включая добавленные позднее.
Текущие фильтры и месяц сохраняются в URL на время навигации по приложению.

