# Сроки аккредитации для выставок

Данные заполняются вручную в разделе **«Сроки аккредитации»** карточки элемента смарт-процесса **«Выставка»**. Оставляйте поле пустым, если такой срок не применяется.

В календаре включите флажок **«Показать сроки аккредитации»**. Для каждого типа конструкций появится отдельная строка. Даты отмечены: бледно-зелёным — `0%`, бледно-жёлтым — `+50%`, бледно-красным — `+100%`. Будущая выставка появится в открытом месяце, если её срок аккредитации приходится на этот месяц.

| Группа | Поля дат |
| --- | --- |
| Одноэтажный стенд | Аккредитация одноэтажного стенда; Аккредитация одноэтажного стенда +50%; Аккредитация одноэтажного стенда +100% |
| Двухэтажный стенд | Аккредитация двухэтажного стенда; Аккредитация двухэтажного стенда +50%; Аккредитация двухэтажного стенда +100% |
| Уличная экспозиция | Аккредитация уличной экспозиции; Аккредитация уличной экспозиции +50%; Аккредитация уличной экспозиции +100% |
| Подвесы | Аккредитация подвесов; Аккредитация подвесов +50%; Аккредитация подвесов +100% |

## Правила заполнения

- Указывайте даты без времени.
- Если организатор не применяет конкретный коэффициент, оставьте соответствующее поле пустым.
- Проверяйте сроки по первоисточнику организатора перед заполнением.
